# 途中撤収・有料場札交換：ルール改善の実験

実施日：2026-10-21。対象：v0.19の12作物、18R、農地6枠。
**検討用の試作と提案。公開アプリ・正式ルールは変更していない。**

## 提案

次の人間による試遊では、まず次の組み合わせを試す。

1. **撤収して別種に植え替える**：通常行動1回。成長中・収穫中の作物を終了させ、同じ農地へ場札の別種を植える。返金なし、そのR以降の旧作物の収穫は失う。新しい栽培費を払う。農地取得費は不要。撤収の追加料金は0Gを第一候補、1Gを比較用に残す。同種への更新は不可。
2. **全場札交換**：自分の通常行動の前に、1手番1回まで2G。通常行動は残る。場札全体を交換し、その後に植える／植え替える／パスを選ぶ。費用は戻らず、同じ野菜や重複した野菜がまた出ることもある。

これは2Gが最適と証明されたという提案ではない。1Gでは交換頻度が高く、3Gでは機会が減るため、中間を初回の試遊候補とした。

撤収だけで1手番を使う案は検証用に残す。価値がゼロではないが、先の再投資まで考えないと損をしやすい。初回のUIでは「別の作物への植え替え」を中心に見せたい。

## 主比較の結果

平均は1人・1シーズンあたり。点数が増えることは、面白さ・戦略の幅・公平性の改善を意味しない。

- 現行：158.89G、パス率27.0%。今回の検証用CPU・192条件での基準。前回の別条件・別CPUの平均とは比較しない。
- 撤収のみ、0G＋1手番：自発的な利用0、得点差0G。この結果だけで無価値と判断しない（下記の追加診断参照）。
- 無料の撤収＋植え替え：得点差+1.08G、1人あたり0.92回。パス率25.4%。
- 1Gの撤収＋植え替え：−0.24G、0.70回。2Gなら+0.04G、0.46回。追加料金を払わなくても旧収穫の放棄と新しい栽培費という負担が既にある。
- 1G＋1手番の全場札交換：+3.43G、0.78回。新たに引かれたカードは、1回の交換あたり支払者が後に0.24枚、他人が1.96枚使った。支払者自身の改善より、次の人への供給になりやすい。
- 1G・手番消費なしの交換：+13.41G、3.50回。18Rの約19%の手番で使う。払えるなら頻繁に確認する操作になる懸念。
- 2G・手番消費なしの交換：+10.18G、2.41回。料金は平均4.83G。交換直後に通常行動で植えた／植え替えた割合は約98%。
- 3G・手番消費なしの交換：+7.51G、1.62回。料金は平均4.85G。使う場面をかなり絞る案。
- **無料植え替え＋2G交換**：+10.76G、植え替え0.97回、交換2.55回、パス率23.6%。
- 1G植え替え＋2G交換：+10.15G、植え替え0.69回、交換2.52回、パス率24.2%。

交換単独の+10.18Gに対し、無料植え替えを併用して+10.76G。単純な収入増の大部分は交換による。植え替えの価値を平均点の上積みだけで評価しない。植え替えは1シーズンに1回前後の局面判断になり、毎手押す作業にはなりにくい。

無料植え替え＋2G交換の得点差は3人で+13.54G、4人で+9.52G、5人で+9.23G。新しい選択肢が3人卓だけ、5人卓だけで成立した結果ではない。

## 撤収単独を追加診断した理由と結果

検証用CPUの「農地を早く空ける価値」は単純な近似であり、撤収のために1手番を捨て、翌R以降に再投資する利益を過小評価しうる。自発利用0をルールの欠陥と断定することはできない。

そこで36の現行対局を進め、P0のR5・R9・R13の108局面で分岐を作った。各局面で、公開情報から残り価値が最も低い成長中の農地を選び、無料の単独撤収を強制した場合と、そのまま通常判断した場合を最後まで進めた。分岐後の初期山札と乱数seedは対にしている。

最終の本人得点は10局面で改善、1局面で同点、97局面で悪化。平均差−21.44G。良くなる例は存在するが、この選び方で安易に撤収すると大きく損をする。未来の最終点で撤収対象を選んだ試験ではなく、最適な撤収方策の上限を求めたものでもない。分岐後の他人の行動変化も含まれ、特定局面の改善を確実な回収額として案内しない。

## 他のルール候補

- **最低保証を切り捨てで半分**：平均−3.72G、パス28.1%。現行12種は、半減しても全収穫を得れば最低保証合計が栽培費以上。これだけでは元本割れする危険な投資は作れない。堅実派／冒険派を作るなら作物ごとの保証設計が別途必要。
- **競合を1枚−1G→−2G**：平均−17.72G、パス28.3%。制裁は強くなるが、新しい操作が増えるわけではない。相手を読む面白さが増えたかは別途測定が必要。今回の最初の試作には重ねない。
- **別作物を挟んでも同種の休みを記憶**：平均−0.14G、パス27.1%。今回のCPU・条件では影響が小さかった。専用の輪作計画を持つCPUを使った検証ではないため、潜在的な価値がないとは断定しない。
- **1手番1枚の制約**：今回変更していない。植え替えは通常行動1回、交換はその前の有料補助行動という役割分担だけ試した。複数植え付けや設備への投資は次の独立した実験にする。
- **終盤・シーズン持ち越し**：今回変更していない。待機が最低1Rあり、残存資産の点数がない現行では、R18の新規植え付けは得点上不利。終盤の退屈さを消すUI上の省略と、残存価値を付けて戦略を変える案は別問題として扱う。

## 判断方式を変えた感度検証

早期回収型、保証重視型、長期回収型の3方式でも、各36条件について現行・無料植替＋交換・1G植替＋交換を比較（324対局）。無料植替＋交換の現行比はそれぞれ+13.35G、+9.73G、+7.56G。1種類の評価傾向でしか成立しない結果ではなかった。

これはCPUキャラクター同士の対戦や勝率の比較ではない。各卓の全員を同じ方式にそろえた感度検証。人間に性格が伝わるかは測っていない。

## 新行動を使わない相手との比較

36条件で、新行動を使う1人を全席に交代させて比較した。相手もルール上は利用できるが、選択方針として新行動を使わない。144の席条件での勝者持分は、同じ席の現行比較25.0%に対し、2G交換のみ46.5%、無料植替＋交換51.0%、1G植替＋交換48.6%。同点優勝は人数で按分。

これは「通常の対戦で勝率51%」という結果ではない。新ルールを無視するCPUを相手にした習熟差の検査。キャラクターの個性を「交換を全く使わない」で表すのは避け、機会を判断する基礎能力を共有したうえで、使う頻度や要求する利益の大きさに個性を付けるべきである。

## 次の試遊で決めたいこと

1. 交換料金2Gと3Gを比べる。交換を「時々使う判断」と感じるか、「毎手確認する作業」と感じるか。
2. 無料植え替えと追加1Gを比べる。旧作物を捨てる判断に十分な重さがあるか。
3. 植え替え前に「失う残り収穫」と「新しい収穫開始」を表示する。未公開の天候を確定値で見せない。
4. 交換は同じ野菜が再び出ること、払ったあとパスする場合もあることを明示する。交換後の結果が不満でも巻き戻しはしない。
5. 一つの変更につき、気持ちよさ・後悔・利用率・初心者の理解・対戦相手への影響を確認する。最低保証・競合・連作記憶を同時に変えて原因を分からなくしない。

## 提案する厳密な処理

- 呪いを使う場合は従来どおり通常行動前。有料交換とどちらを先にするかは試遊実装時に統一する（この実験ではCPUは呪いを先に判断）。
- 交換は手番に1回まで。料金を先払い。旧場札を一時的に避け、山札／従来の捨て札から同じ枚数を補充してから旧場札を捨て札にする。同じ実体カードをその場で引き戻さないが、別の同種カードは出る。
- 交換後も普通に植える・植え替える・パスを行う。交換自体はパス判定に数えないため、通常行動で全員がパスすると従来の無料一掃も起きる。
- 植え替えは現在の農地の旧作物と異なる作物だけ。返金・即時収穫なし。新しい栽培費を払う。現在Rの旧収入も失い、待機を最初から数える。農地は取得済みのまま。
- 別種に植え替えたあとの連作制限は、初回の試作では現行どおり直前作のみ。連作の記憶保持案を混ぜない。
- 単独撤収の比較案では、農地を保持して終了状態へ戻す。同作物の休みは撤収翌RからCラウンド。返金なし。通常行動を消費し、その手番に植え直せない。

## 実験方法と限界

主比較は14案×192条件＝2,688対局。495作物構成から `(index×113) mod 495` で32構成を選び、3／4／5人×各2seed。全員初期8G、開始席0で固定。各人数・seedの半数はシーズン2を模して最終席1人に呪い権利を配り、半数は呪いなし。累計得点で権利が決まる複数シーズンの追跡ではない。

条件ごとに初期作物山札・イベント山札・乱数seedをそろえ、作物補充とイベント更新の乱数系列を分離する。したがって有料交換で余計に乱数を使っても、比較相手の天候の並びを変えない。すべての主比較の天候一致を検査した。交換や選択で場札の将来は変わるので、全手番で同じ場札を強制する比較ではない。

公開済みの天候・呪い、現在の農地の収穫予定、競合、最低保証、資金を用いる検証専用CPUを作った。公開されていない将来の天候は補正0、他人の将来の植え付けは予測せず、資金の時間価値と農地の機会費用を近似する。

場札交換の期待値は、各種10枚から現在農地と場札の枚数を引いた、公開情報で分かる補充候補の構成を用いて超幾何分布で計算。実際の山札順は見ない。手番消費の交換は、他人に先に選ばれるため期待値の50%を保持する固定近似を置く。この値の最適化はしておらず、手番消費案には追加の不確実性がある。期待改善が0.5G相当を超えたら実行する。

基準の評価係数は収入の時間割引0.96/R、農地機会費用0.9G/R。早回し0.87／1.2、保証重視は基本係数に上振れ部分30%控除、長期型0.995／0.5。将来の農地利用価値は単純な近似。これらは最適な人間判断でも、完全な探索AIでもない。

得点差の探索区間は、32作物構成を単位に再標本化した2,000回のブートストラップの2.5〜97.5百分位。構成の選定は固定で、495全体や人間集団に対する信頼区間とは解釈しない。平均点の増加を戦略の深さの直接の指標にしない。

人間の満足度、初見の操作負担、全495構成、複数の同時呪い、長いマッチでの公平性、固定キャラクター同士の優劣は未検証。
