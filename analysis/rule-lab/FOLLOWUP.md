# v0.20採用・追加候補・CPUの知覚モデル

2026-10-21。採用：無料撤収＋別種への植え替えを通常の一手に含める。2G全場札交換は自分の手番に一度、通常行動前に任意使用。正式ルールは `hatasaku_rules_v0.20.md`、UI・CPU・保存互換は `web-lite/SPEC.md`。

## 追加比較：新しい2案と組み合わせたらどうなるか

`followup.ts` / `followup.json` で再現可能。基準は採用案の「無料植え替え＋2G交換」。前回同様、32作物構成×3/4/5人×2seed（片方は呪い権利1人）＝192条件を各案で完走。各案全員が同じ検証用CPUを使う。ルール比較は6案×192＝1,152対局。前回の検証用CPUと同じ一手評価を保ち、本番の新CPUとの変更を混ぜない。

基準の1人平均は169.65G、植え替え0.97回、交換2.55回、パス4.22回／18R。

- **最低保証を半分**：平均−2.30G、植え替え1.03回、パス4.29回。植え替え増加は0.06回と小さい。全収穫できれば栽培費を下回らない作物構成のままなので、事業失敗の危険を強くする変更にはなっていない。現段階で採用する根拠は弱い。
- **競合減額を2倍**：平均−16.84G、植え替え0.98回、パス4.37回。単に収入を減らす作用が目立ち、再投資を増やす効果はこのCPUでは見えない。他者の栽培を強く気にする動機は増すが、最低保証への到達を早めると、それ以降の競合差が消える。即採用は勧めない。
- **異種作物を挟んでも連作履歴を保持**：平均−0.20G、植え替え0.97回、パス4.23回。今回の対局では影響が小さい。撤収→異種→元の作物という回避を防げるが、過去履歴をスマホのミニカードに追加表示する負担がある。長期の輪作を探索しないCPUでは価値を過小評価している可能性があり、将来検証に残す。
- **交換を1G**：平均＋3.60G、交換3.70回。交換回数は基準より45%増加。選択肢を探す操作が増えるため、得点が高いことだけでは優位にできない。
- **交換を3G**：平均−2.32G、交換1.70回。回数は33%減少。交換を少数の特別な決断にしたい場合の候補。現在は2Gを維持。

これらは戦略の最適性や楽しさの順位ではない。同じ初期条件の比較でも行動が変われば、以後の作物・天候の経路が変わる。32構成は全495構成の悉皆調査ではなく、異なる2seedも独立な十分大きい標本ではない。わずかな得点差は優劣と解釈しない。数値を理由に追加ルールを本番適用していない。

## さらに残す候補（今回は未シミュレーション）

1. **1Gで場札1枚だけ交換、2Gで全交換との二択**：欲しい作物を残せるため「慎重に選別する」性格が出せる。一方、交換対象を選ぶタップが増え、共有場札の調整を自分だけに有利に使いやすい。新しい2G交換を体験してから比較する優先候補。
2. **作物1枚の予約・取り置き**：遅い作物や次Rの購入を計画する個性を作れる。共有場札を取り合う緊張が減り、予約された作物が全員に見えるか・費用・失効時期など新規ルールが増える。まずは保留。
3. **行動回数を増やす有料追加手番**：資本を貯めて集中投資する戦略を作れるが、先行者が追加手番でさらに稼ぐ危険が強い。農地取得・収入への影響が大きく、今回の小さな追加の次に入れる案ではない。
4. **最終ラウンドの自動パス**：待機1以上の現作物はR18に植えても一度も収穫できず、終了時の作物価値も0なので、勝利得点のためにはパスが支配的。ただし合法な操作を奪う変更と、何もできないと知らせるUXは分ける。今回追加の `❌`／`🔺−N` が先。ルールは変えない。
5. **収穫・撤収への独自のキャラクターボーナス**：見た目には伝わりやすいが、CPUだけルールが違うゲームになる。まず全員同じルールのまま、注意の偏り・投資好みでどこまで個性が伝わるかを見る。

## CPUは「読む精度」と「好み」を独立にする

実装 `web-lite/strategy.ts` は公開情報 `PublicView` だけを受け取る。未来の山札順・他者の未公開対象へアクセスしない。ルール上閲覧できる呪いは既知として扱える。全員が植え替えと交換を利用できる。

読む精度：
- 天候を見ない／目立つ1枚だけ見て時期を合わせない／収穫ごとに期間と重なりを照合する。
- 競合を見ない／同種の栽培農地の数だけ見る／収穫Rの重なりを照合する。自分の他農地も競合。
- 呪いの投資への影響を無視／閲覧可能な効果だけ計算／公開盤面から未確定の対象も推測。

好み：早く回収したい度合い、農地を長く占有するコスト感覚、最低保証を好む度合い。天候を正確に読める人が、必ず長期投資好きになるようには結びつけない。

「天気に敏感だが時期を取り違える」「畑の数には敏感だが、収穫が重ならないことには気付かない」は、毎回25%ランダム行動する方法とは異なり、失敗の理由が一貫する。将来、台詞や注目するカードの演出でこの理由を見せる余地がある。今回のUIはCPU名をタップすると考え方を読む控えめな方式。

初期試作は「実り重視」「天気に敏感」「先読み派」「堅実派」。名前や人物設定の完成版ではない。プロフィール値は `SPEC.md` と同実装に記載。

## 知覚だけを変えた対戦：576対局

4人・24条件（12作物構成×2seed、半分に呪い権利）について、対象CPUの席を4通り入れ替えて96対局／段階。ほかの3人は先読み派。対象の時間割引・機会費用・リスク好みはすべて先読み派と同じにして、知覚の差だけを変えた。生産版の4プロフィール同士の強さの調整ではない。勝者持分は同点優勝なら人数で分ける。対象も正確に読む基準では対称性から25%。

- 作物だけ：平均153.31G、勝者持分14.6%、正確に読む場合との判断不一致29.6%。
- 天候だけ大まか：146.98G、10.4%、不一致37.3%。
- 天候だけ正確（競合・呪いは見ない）：156.41G、15.1%、不一致22.1%。
- 天候正確・競合大まか（呪いは見ない）：151.83G、12.0%、不一致28.4%。
- 天候・競合・公開呪いを正確：160.68G、25.0%、不一致0.10%。
- 上記に未確定呪いの予測も追加：160.30G、25.0%。

**「大まかに見る」と「見ない」は強さの単純な上下関係にならない。** 目立つ好天に釣られる、時期の違う同種栽培まで避ける、といった人間らしい偏りを作れる。読みの違いは約2〜4割の判断で現れたため、個性が弱すぎて作れないという懸念には、少なくとも行動面の差を作れるという答えが出た。ただしプレイヤーがそれを認識できるかは、対人テストが必要。

**未確定呪いの予測の追加効果は今回ほぼ出なかった。** 意思決定が変わった割合は0.1%程度で、予測ありが0.38G低い。そもそも呪いの局面が限定的で、対象推測も未校正の一手モデルなので、予測能力に価値がないとは断定できない。今は主役の個性にせず、先読み派の補助能力とする。予測が外れる可能性を明記し、隠し情報を知るCPUで代用しない。

## 限界と次の評価

- 標本の小さい勝率差・平均得点の差から、人間の楽しさや全状況の強さを断定しない。
- 交換価値と植え替え価値は一手評価。複数Rの再投資、相手の反応、将来の新規植え付け、非公開天候を完全には探索しない。
- 大まかな競合は意図的に時期を無視するため、弱すぎる可能性がある。今後は「重なりを全く見ない」か「ときどき照合する」かも、難易度として検討できる。
- 呪い予測は次4Rの公開された被害と自損の重みから仮説を立て、未行使権利の行使確率を暫定25%と置く。予測校正・長期の勝ち筋は未評価。
- 今回の結論は、新ルール2案を実装し、情報処理の癖でCPUを試作して遊べる状態にすること。他の候補は本番に自動採用しない。
